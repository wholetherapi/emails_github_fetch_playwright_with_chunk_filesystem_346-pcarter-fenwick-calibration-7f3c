# Fenwick Calibration

**Status:** Released (public) — v1.1.0. Public release went live on 2026-11-06.

Calibration layer for tabular foundation models: lightweight posterior correction on top of frozen representations, with the thirty-benchmark evaluation suite used in the paper.

## Repository layout

- `src/` — core library and reference implementation
- `data/` — released data cards and benchmark splits
- `experiments/` — scripts that reproduce the paper's tables and figures
- `configs/` — experiment configurations

## Citation

P. Carter, R. Delgado, A. Mensah. Calibrated Uncertainty for Tabular Foundation Models. NeurIPS, 2026.
